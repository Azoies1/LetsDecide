# Security Policy

## Reporting

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/azoies1/letsdecide/security/advisories/new).
Please do not open public issues for them.

## Scope

- API keys: leaking into errors, logs or built requests beyond the intended header.
- Parsing: panics, unbounded work or misreads on untrusted provider responses.

Supported: the latest released version.
